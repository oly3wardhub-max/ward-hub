# Ward Hub

A calm, fast app for a ward's leaders: Today, Sunday planning and conducting, calendar, people and messages.

- **App** (this repository): plain HTML, CSS and JavaScript, hosted free on GitHub Pages. Installs on iPhone and Android.
- **Engine** (`engine/Engine.gs`): a Google Apps Script that lives inside the ward's own Google Sheet.
- **Data**: only in the ward's Google Sheet. This repository holds **no ward data**; the demo uses invented names.

Setting up a copy for another ward: open `setup.html` (the "Setting up Ward Hub for another ward?" link on the sign-in screen).
